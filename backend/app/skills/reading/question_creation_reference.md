# IELTS Reading Module — Question Creation Reference

A working reference for generating IELTS Reading passages and questions (Academic & General Training).

---

## 1. Overall Test Structure

| Element                    | Detail                                                                      |
| -------------------------- | --------------------------------------------------------------------------- |
| Total passages             | 3 (Academic); GT has 3 sections, Section 1 often split into 2 shorter texts |
| Total questions            | 40                                                                          |
| Total time                 | 60 minutes (no extra transfer time)                                         |
| Total word count           | ~2,150–2,750 words                                                          |
| Passage 1                  | ~750–850 words, easiest                                                     |
| Passage 2                  | ~850–950 words, medium                                                      |
| Passage 3                  | ~900–1,050 words, hardest (abstract/argumentative)                          |
| Questions per passage      | ~13–14                                                                      |
| Question types per passage | Usually 2–3 different types mixed                                           |

**GT-specific note:** Section 1 = everyday/social survival texts (ads, notices, timetables); Section 2 = workplace texts; Section 3 = one long, general-interest text similar to Academic Passage 3.

---

## 2. Passage Design Rules

- **Topic range:** non-specialist, general interest — science, history, social issues, environment, culture, technology, biography. No topic requiring prior specialist/expert knowledge.
- **Source style:** written as if from books, journals, magazines, newspapers — factual, descriptive, discursive, or analytical (not fiction/narrative for Academic; GT Section 1 can be functional documents).
- **Structure:** must be organized into clearly identifiable paragraphs (needed for Matching Headings/Information/Features).
- **Difficulty progression:** vocabulary, sentence complexity, and abstraction should increase from Passage 1 → 3.
- **Self-contained:** all answers must be derivable from the passage alone — no outside knowledge required.
- **One idea per paragraph (roughly):** each paragraph should have a distinguishable main idea/theme for heading-matching to work fairly.

---

## 3. Core Rule for ALL Question Types

> **Every answer must be locatable and verifiable directly from the text.** Questions must not rely on inference beyond what a careful reader can justify from stated information.

> **Paraphrasing is mandatory.** Question wording should NOT copy the passage verbatim — use synonyms, different sentence structure, or reworded phrasing. The candidate's skill being tested is matching meaning, not scanning for identical words. Keywords in the question (names, numbers, dates, unique nouns) may remain unchanged as "anchors."

> **Questions follow passage order** (except Matching Headings/Features/Sentence Endings, and Multiple Choice with multiple answers, which may not).

---

## 4. Question-Type-Specific Rules

### 4.1 Multiple Choice

- 3–4 options (A, B, C, [D]); one correct unless explicitly "choose TWO."
- Distractors must be plausible — either partially true, true but not what's asked, or a common misreading — never nonsensical.
- Avoid options that are simply "not mentioned" as the sole distractor; base distractors on real content from the passage.
- Question stem should not telegraph the answer through mismatched grammar/length.

### 4.2 Identifying Information (TRUE / FALSE / NOT GIVEN)

- Used only with **factual/descriptive** passages.
- **TRUE** = statement agrees with the facts stated.
- **FALSE** = statement contradicts the facts stated.
- **NOT GIVEN** = no information either way in the passage — this must be a genuine absence, not a trick of vague wording.
- Rule of thumb for writers: only include NOT GIVEN items where the topic is mentioned/adjacent but the specific claim truly isn't addressed — don't make it feel like a "search harder" trap.
- Avoid absolute qualifiers (always/never/all) unless the passage genuinely supports/contradicts that absolute claim — these are common trap constructions but must be fair.

### 4.3 Identifying Writer's Views/Claims (YES / NO / NOT GIVEN)

- Used only with **opinion/argumentative** passages (the writer's stance matters).
- **YES** = statement agrees with the writer's claims/opinions.
- **NO** = statement contradicts the writer's claims/opinions.
- **NOT GIVEN** = the writer expresses no view on this.
- Distinguish from True/False: this tests the _writer's opinion_, not simple facts.

### 4.4 Matching Headings

- A list of headings (usually passage-paragraphs + 2–3 extra distractor headings) matched to paragraphs/sections.
- Provide **more headings than paragraphs** (typically +2/+3) so it can't be solved by elimination alone.
- Each heading should capture the **overall gist** of a paragraph, not a minor detail within it.
- Avoid headings that could plausibly fit two paragraphs — each correct match should be defensible as uniquely best.
- Do not reuse exact keywords from the paragraph in the heading — this should be tested at the "gist" level, more paraphrased than other question types.
- Sometimes one paragraph is given as an example (already matched) to demonstrate the task.

### 4.5 Matching Information

- Statements (specific details, examples, reasons, comparisons, dates) matched to the paragraph that contains them.
- Unlike headings, this targets **specific pieces of information**, not paragraph gist — a paragraph can be a correct answer more than once.
- Only use with passages where information is somewhat distributed/non-linear (otherwise it reduces to trivial sequential matching).

### 4.6 Matching Features

- A set of statements matched against a list of options (people, theories, time periods, categories, places) explicitly named in the passage.
- Options list should be short and clearly enumerable in the text (e.g., named researchers, named places).
- Some options may be used more than once, or not at all — this must be stated in the instructions.

### 4.7 Matching Sentence Endings

- First halves of sentences (based on the passage) matched to correct second halves from a list.
- Provide **more endings than first-halves** (extra distractors) so the last one isn't "given away."
- Endings must be grammatically consistent with every stem to prevent grammar-based shortcuts (i.e., don't let syntax alone reveal the answer).
- Only one ending should be logically AND factually correct per stem.

### 4.8 Sentence Completion

- Gapped sentences based on passage content, filled using words taken **from the passage**.
- Always specify a strict word limit: "NO MORE THAN ONE/TWO/THREE WORDS (AND/OR A NUMBER)."
- The word(s) needed must exist in the passage in a form that fits grammatically into the given sentence.
- Do not require the candidate to alter the word's form (e.g., pluralize, change tense) unless it's a trivial/obvious fit.

### 4.9 Summary / Note / Table / Flow-Chart Completion

- A summary (or notes/table/flow-chart) of part or all of the passage, with gaps.
- Two variants:
  - **From the passage:** fill gaps using words from the text, with a word limit.
  - **From a word list/box:** a bank of possible words/phrases is given (often with distractors) — no word-limit instruction needed here since options are fixed.
- The summary should paraphrase the original passage overall — only the gapped words are lifted from the passage.
- Gaps should test comprehension of relationships (cause/effect, sequence, comparison), not just isolated vocabulary.

### 4.10 Diagram Label Completion

- Labels for a diagram (process, mechanism, object with parts) filled using words from the passage.
- Passage must contain a clearly describable process or labeled structure in prose form.
- Word limit rule applies as with sentence/summary completion.

### 4.11 Short-Answer Questions

- Answered using words taken directly from the passage, under a strict word limit (commonly "NO MORE THAN TWO/THREE WORDS").
- Typically factual: names, numbers, places, reasons, things listed.
- Should have one unambiguous correct answer locatable in a specific part of the text.

---

## 5. General Construction Rules (apply across all types)

1. **Word-limit instructions are mandatory** wherever the candidate produces text (completion/short-answer types) — state it explicitly every time, and enforce it consistently within the answer key.
2. **No overlap/ambiguity:** each question should have exactly one defensible correct answer per the passage.
3. **Balanced difficulty spread:** within each passage, mix easier "locate and match" items with harder "infer the gist" items.
4. **Instructions must be unambiguous:** every question set needs a clear instruction line (e.g., "Choose the correct letter, A, B, C or D," "Do the following statements agree with the information given in the passage?").
5. **Answer key must be exact:** specify accepted answer(s) including acceptable minor variants (e.g., singular/plural, alternative spelling) where legitimately equivalent.
6. **Avoid cultural/regional bias:** don't assume knowledge specific to one country or background.
7. **No leakage between questions:** answering one question should not give away the answer to another (except intentionally sequential types).
8. **Distractors must be genuinely tempting**, not simply wrong — should reflect common misreadings, partial matches, or nearby but incorrect details.
9. **Paraphrase consistently at the level appropriate to the type** — Matching Headings needs the most paraphrasing (gist-level); Sentence/Summary Completion needs the least (near-verbatim lift for the blank itself, paraphrase around it).

---

## 6. Quick Checklist Before Finalizing a Question Set

- [ ] Passage length appropriate to its position (P1 < P2 < P3)
- [ ] Question types match passage style (factual → T/F/NG; opinion → Y/N/NG)
- [ ] Word limits stated wherever required
- [ ] Extra distractors included for Matching Headings / Sentence Endings
- [ ] Every answer traceable to a specific part of the passage
- [ ] No verbatim copying between question stems and passage (except intended keyword anchors)
- [ ] NOT GIVEN items are genuine absences, not just hard-to-find
- [ ] Answer key includes accepted variants and exact word-limit compliance
- [ ] Overall progression: 13–14 questions per passage, 40 total
